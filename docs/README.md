## Viewing the OpenAPI spec

- Paste `openapi.yaml` into <https://editor.swagger.io>, or
- Import it into Postman / Insomnia (**Import → File**), or
- Use the Swagger Viewer / OpenAPI extension in VS Code.

Keep `API.md` and `openapi.yaml` in step whenever a route changes.
